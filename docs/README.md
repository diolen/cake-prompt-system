# Основная задача системы это генерация качественных промптов для LLM.

## Workflow
Анализ кода -> Генерация промпта -> Отправка в LLM

## Схема пайплайна системы
1. Анализатор кода
   - Анализирует код на основе фреймворка CakePHP v2/v3/v4 и языка PHP 5.6
   - Определяет зависимости и связи между файлами на основе анализа кода
     - Controller -> Model
     - Model -> Model
   - Определяет уровень влияния (Score) и связность (Connectivity)
   - Возвращает структурированный анализ в формате JSON
     - Проверяет валидность JSON

2. Генерация промпта
   - Генерирует промпт на основе анализа кода
     - Тип задачи (FEATURE, REFACTOR, DEBUG)
   - Отправляет промпт в LLM в ручном режиме
